# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-08-13
### Added
- Per-device selection for Tuya local protocols 3.1, 3.3, 3.4, and 3.5.
- Read-only Test & Detect action for finding a working protocol version.

### Changed
- Default protocol for newly configured plugs is 3.3.
- Corrected package manifest paths and documented the fork's OctoPrint install URL.

## [0.1.0] - 2023-03-25
### Added
- Initial release based on [OctoPrint-octotuya by ziirish](https://github.com/ziirish/OctoPrint-octotuya).
